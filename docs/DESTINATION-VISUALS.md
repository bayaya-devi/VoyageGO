Les pays absents de ce registre utilisent l'atmosphère graphique VoyageGo. Aucun visuel non vérifié n'est substitué automatiquement.

## Données géographiques

Le globe utilise les frontières administratives publiques [Natural Earth Admin 0 — 1:50m](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries/), version 5.1.2. Le fichier GeoJSON local conserve les polygones, multipolygones et anneaux intérieurs nécessaires à la sélection précise des territoires et des îles.
